# EPI Fácil — site funcional

Site integrado a partir das telas do Stitch.

## Funcionalidades
- Busca de EPIs por nome, categoria e risco
- Filtros rápidos por risco
- Setores interativos com checklist de EPIs
- Cards de EPI clicáveis
- Página de detalhe do EPI com navegação para NR-06
- Navegação entre Home, Setores e Normas
- Confirmação de leitura salva no navegador
- Layout responsivo

Abra `index.html`. O projeto utiliza Tailwind CDN e Material Symbols, como as telas originais do Stitch.


## Melhorias desta versão

- Busca por nome, categoria e risco.
